# 类别分流与内容保留

| 类别 | 提取内容 | 版型/后续处理 |
| --- | --- | --- |
| 明信片、海报、封面等平面物品 | 按确认范围提取设计 | 使用用户给出的目标宽高，通常为 custom |
| 周边 PB（写真集）内页 | 按确认范围提取单页画面，保留页内背景、文字与排版 | 使用 custom；书页明显弯曲、书脊遮挡或跨页画面先评估，四角拉正不等于曲面展开或遮挡恢复 |
| 小卡正面 | 整面设计，不含卡外环境 | 常见预设或自定义尺寸，按 [版型](formats.md) 先确认再锁比例 |
| Instax 正面 | 仅原照片窗口，排除实拍白框 | 按传入的 Mini / SQ / Wide 比例返回画面；网站后续微调并装入对应固定框 |
| Instax 背面 | 原始手写墨迹图像内容 | 放回对应空白背板；不 OCR 重排或重画笔迹，不套正面画面比例 |
| 覆膜票根 | 纸张轮廓和实际印刷内容 | 按纸而非覆膜边界；不重建遮挡/涂抹信息，另定几何 |
| 彩带/织带 | 已拍到的展开印刷区域 | 先评估折痕、曲面和重叠，不能直接套平面卡片模型 |

这些脚本只负责平面几何，不自动分割主体、提取墨迹、展开曲面或保护文字；其他类别仍须实际试样，不由已有小卡/拍立得结果推定成功。

## 保留真实内容，检查力度与问题相称

- **画面内容**：印在照片里的 V 手势、阴影、景深、舞台光点和原设计颗粒保留。只有实物制造与再次拍摄额外带来的材质/光照是去除对象；不确定细纹优先保留。
- **画内背景**：白色、黑色、其他颜色、渐变及暗场都属于设计，不抠除，不因颜色深就自动提亮。透明区只由确认的物品外轮廓决定；完整矩形照片应整体还原，不能把人物抠出后当作还原成品。
- **文字、签名、手写**：保留原字样、笔画及布局，不编造、不 OCR 重排、不生成补字。处理前留存源图区域；有可见实质变化时针对对应区域保留/恢复实际图像内容，核对接缝。不要在没有问题时自动堆叠复杂保护流程，也不承诺生成后逐像素相同。
- **二维码**：保留其在设计里的位置、大小和可见图案即可。不要求可扫码、解码、码点完全一致或专门校正；轻微生成差异不构成扫码工程的理由。明显消失、变成别的图或版式改变时才针对视觉问题处理，不主动访问其编码链接。
- **颜色**：原图色相关系是依据；避免高饱和生成配色、过强冷暖偏移和无依据自动提亮。暗场演出保留现场气氛，之后由用户用四项基本调节决定偏好。
