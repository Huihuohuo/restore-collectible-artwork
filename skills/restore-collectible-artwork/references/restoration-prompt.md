# 源图编辑指令

介入位置：已经按用户确认的 [目标比例](formats.md) 提取、透视校正之后，几何核对与基础微调之前。本步负责电子稿观感，不负责最后相框或虚拟材质。保持输入角色明确，以本次正视图为唯一内容来源。

按照片实际内容适配下面的指令，不照搬案例人物或色彩：

> 输入图 1 是唯一编辑对象与内容来源，已提取并按所选版型比例拉正。请从实物照片反向还原接近制造前的二维电子稿观感，输出干净、连续的原画面。
>
> 减弱实物印制、纸塑基材及再次拍摄额外带来的表面响应、反光、色偏和照明不均。保留原设计的颗粒、渐变、纹样，以及画面本身的光影、景深与暗场气氛。不能可靠区分的细纹优先保留。
>
> 保留原人物、表情、五官比例、手势、服饰、背景、构图和完整裁切关系；不美化、换脸、移动主体或补画不可见细节。画内的白底、黑底、其他颜色、渐变和暗场都属于原画面，完整保留，不做人像抠图或按颜色去背景。以源图颜色关系为准，避免强烈冷暖偏色、过饱和、过锐或重新打光；不因“清楚”就把夜景提成亮景。
>
> 列出本图必须保留的具体内容。文字、签名和手写保持原字样与布局，不重写、补写或 OCR 重排；二维码保留其视觉位置与图案，不重新生成一个码或要求扫码性。返回后按实际视觉变化核对，文字约束本身不是无损保证。
>
> 保留输入的版型比例、方向和画面范围，完全平面。不要添加材质、投影、厚度、立体边缘、桌面、标识或假棋盘格。只返回还原图，不输出对照排版。

按已确认轮廓补上唯一适用的输出要求（准备报告的 `generation`）：

- **完整矩形 / `full_canvas`**：保留整幅设计及其全部背景，完整不透明画面铺满画布，严格保留目标方向、比例和裁切；不添加透明留白、内缩边框、外部环境或投影。这既适用于整张矩形照片/明信片/海报，也适用于独立照片窗口。内置工具用 `transparent_background: false`，避免把画内背景理解成应抠除的环境。
- **带外部透明区的轮廓 / `transparent_object`**：保留圆角等物品轮廓，物品外真实透明 alpha，物品内所有内容和背景不透明。内置工具用 `transparent_background: true`；只抠除轮廓外区域，不抠除人物周围的印刷背景。

独立画面窗口不生成白框、白边或卡外环境；整张相纸由宿主另行合成。最终 alpha 沿用已确认参照，完整矩形没有画外区域时可全部不透明，不必为了“透明 PNG”额外添加透明边距。

在 Codex 中优先内置编辑工具，先查看本地编辑对象并显式引用。完整矩形使用无留白的准备输入；若旧准备文件有透明边距，改用同次 `reference.png`，不改尺寸或旧文件。保持原图方向，旋转若有需要由几何步骤显式处理。

生成工具不保证比例和细节锁定；返回后仍与固定比例参照核对。先一版，有具体问题再定向处理，不为过度检查连续整图重生。记录实际指令与工具结果；工具不可用时保留准备结果并说明限制，不声称 skill 自身能调用任意平台生图。

输出称为依据实拍的视觉还原，不称真实工程文件、原始图层或隐藏内容恢复。
