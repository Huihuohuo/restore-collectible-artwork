# 周边高清扫图

主要用于小卡、明信片、拍立得、周边 PB（写真集）内页等的扫图还原，能力面向平面实物中的画面。源照片提供内容和几何，源图编辑改善外观，非生成式配准按需校正位置。需要宿主提供图像编辑能力；本地脚本不调用模型或网络。五种常见版型是快捷预设，不是适用范围的边界；不承诺恢复真实源文件、图层或不可见内容。

## 1. 先取得对象和尺寸

在提取、拉正或生成之前，必须知道：

- 这是什么对象（`object_type`）。
- 要还原的目标宽、高及单位（`dimensions`），明确方向。
- 如有边框，尺寸描述整件物品还是内部画面；自定义任务明确 `target`。

用户已提供的信息不重复询问；缺少哪项先问哪项，得到答案才继续。**不从照片或物品名称猜测尺寸，不默认套用标准三寸。** 可以展示五个常见预设的尺寸让用户明确选择；只说“小卡”“Mini”不等于确认了目标宽高。用户可给毫米、厘米、英寸或目标像素尺寸。

读 [版型与自定义尺寸](references/formats.md)。选择匹配的常见预设，或用 `format_id: "custom"` 表达用户给定的其他尺寸；用户尺寸优先，不挪用相近预设。脚本也拒绝缺失对象或尺寸的配置。

## 2. 提取与拉正

看原图并保留源文件，按 [几何处理](references/geometry.md) 为本张照片标定四角，运行 `scripts/prepare_artwork.py prepare`。四角是这张照片的源像素坐标，不能照抄示例。

需要辅助时，用 [四角与圆角诊断](references/outline-diagnostics.md) 从本图粗四角寻找候选边线，查看四角和边缘放大对照。圆角从未加遮罩的实拍估计；原本同形的四角可共用本物品的拟合值，不跨物品套固定半径，不让用户测圆角。候选不直接成为成品裁切；边线、圆角和必要的内缩分开核对，不统一内缩一个百分比。

整件平面物品提取完整设计，排除物品外部环境；拍立得正面仅提取内部照片窗口，排除实拍白框。固定相框是后续独立操作。其他提取范围见 [类别与内容保留](references/category-routing.md)。

先锁目标比例，再拉正；PNG 分辨率独立于实体尺寸。保留 `reference.png` 作不可变几何参照；它还含实拍光影，不能称为已完成还原的初版。

## 3. 还原外观

按 [源图编辑指令](references/restoration-prompt.md)，以本次准备报告推荐的输入为唯一内容来源做一次源图编辑。使用宿主支持的工具；如提供 imagegen 技能，遵循其要求并先查看本地输入。

减弱制造和再次拍摄引入的反光、表面响应、色偏和照明不均。保留原人物、构图、手势、颜色关系、画内光影、景深与印刷纹理；不把印在图里的手或颗粒当作外部干扰删除。不确定的细纹优先保留，暗场保持暗场。

文字、签名和手写保留实际字样与笔画，不 OCR 重排或补字；二维码保留可见图案与位置，无需解码或像素级修复。生成约束不保证保真，必须检查实际结果。

**画内背景属于设计，不按颜色深浅抠除。** 白底、黑底、渐变、夜景和舞台暗场都保留；透明范围只由已确认的物品轮廓决定。

准备之前先选宿主能实际返回的输出方式：完整矩形、独立画面窗口，以及不支持透明输出或能力未知的宿主，使用 `generation_layout: "full_canvas"`。圆角小卡也可走此分支：生成完整不透明画面，最后套回参照圆角。支持真实透明输出且适合该任务时可用 `transparent_object`。生成画布与最终轮廓是两件事；按准备报告 `generation` 调用工具。不凭“小卡”名称做人像抠图，独立画面不生成白框。

先一版，发现具体问题再针对处理；先检查输出方式、裁切和参照，避免反复整图重生。保存实际提示词、返回结果和重试记录。

## 4. 核对并先交付初版

按 [连续处理](references/fast-path.md) 完成完整画布检查或主体定位、等比归一、按需对齐和导出。完整矩形不自动裁去边缘；透明物品定位针对生成后的单个正视主体，不识别原始照片四角。画内背景被误删时停止，不能靠覆盖 alpha 或拉长边缘把人物抠图伪装成完整画面。新比例也必须满足匹配、形变和边缘检查，不通过放宽阈值强行校正。

检查颜色、人物、印刷内容、构图和内部位置。**同尺寸、同 alpha 不代表内部构图对齐。** 配准只重采样已有还原图，源参照仅提供坐标和 alpha，不修复被重画的细节。匹配失败或内容变化明显时处理实际问题，不把失败结果宣称为已检查的初版。

通过几何检查并完成实际内容复核后，**先展示 `digital-artwork.png` 并提供下载**，明确它是未调色的还原初版，也是保留的母版。用户满意就直接结束；不要为了等待调色而延迟交付，也不要自动套用一组调色参数。

整件物品输出 RGBA，仅实际存在的外部区域透明；完整矩形填满画布时，整张不透明是正确结果。拍立得输出对应比例的不透明照片窗口。保留源图、参照和初版，不覆盖已认可文件。

## 5. 可选人工调色

用户希望调整时再进入 [调色工具](references/color-adjustments.md)。提供亮度、对比度、饱和度、色温，进阶项提供色相；全为零时精确保留初版。每次从同一初版重新计算，不累计处理，也不再生成图片。

支持交互的环境可运行 `scripts/adjust_artwork.py preview` 生成自包含离线 HTML；提供初版下载、前后对比、重置、当前调整 PNG 导出和参数保存/载入。不支持 HTML 时，用同脚本的 `apply` 根据用户明确要求的参数输出派生图。只想“暖一点”等定性调整时，说明本次采用的参数并让用户查看结果。

只调整还原画面；尺寸、构图和 alpha 保持固定。独立白框不进入调色输入，调色后才由宿主另行合成。保留初版及调整参数，另存调整成品。亮面/哑光、厚度、投影等材质不属于本次还原与调色。
