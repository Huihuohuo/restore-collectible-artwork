# v0.2.0 · 周边高清扫图

用于小卡、明信片、拍立得、周边 PB（写真集）内页等的扫图还原。从实拍照片中提取、拉正画面，减弱反光、实物材质和拍摄色偏的干扰，整理为清晰、平整的 PNG 电子图稿，支持自定义尺寸与后续调色。

## 本次更新

- 对外名称改为「周边高清扫图」，内部 ID 继续使用 `restore-collectible-artwork`，旧调用方式保持兼容。
- 五种常见版型保留，新增自定义尺寸；处理前先确认对象类型、宽高和单位，缺少信息时先询问。
- 完成比例、内容检查后先交付可下载的未调色 PNG 初版；用户满意可直接采用。
- 新增可选离线调色：亮度、对比度、饱和度、色温及进阶色相，支持对比、重置、图片导出和参数保存。每次从同一母版计算，不重新生成。
- 完整矩形照片保留整幅不透明画面，圆角等轮廓仅物品外部透明。画内白底、深色背景、渐变和暗场都保留，并加入画内透明缺损检查。

## 下载与使用

下载本页附件 **restore-collectible-artwork-skill.zip**，将解压后的整个同名技能文件夹放入支持的技能目录。该 ZIP 与源码压缩包用途不同：ZIP 附件只包含运行需要的说明、脚本与调色页面模板。

升级前保留旧版本。Python 工具需要 NumPy 和 Pillow；图像编辑能力由运行平台提供。PNG 初版先交付，调色按需使用。拍立得调色只作用于照片内容，独立白框不参与调色。

## 验证与适用范围

43 项检查通过，覆盖输入信息、自定义尺寸、五个预设、几何保护、背景缺损拦截、调色与导出；本地安装包解压后也通过相同检查。两张已认可样例复跑结果与原母版文件完全一致，私人照片不包含在发行包或仓库中。

这是依据实拍的视觉还原，生成可能改变细节，不等于恢复真实源文件或不可见内容。PB 内页需要先评估书页弯曲和书脊遮挡。几何检查不能代替内容复核，单个成功案例不代表固定耗时或一次成功率。
