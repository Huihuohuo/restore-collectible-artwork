# v0.2.1 · 周边高清扫图

本次改善圆角物品在不支持透明输出的图像工具中的处理路径，并补充源照片四角、圆角和边缘检查的辅助工具。

## 本次更新

- **兼容不透明输出。** 圆角小卡可以使用完整不透明画布，归一后恢复已确认参照的圆角与透明范围。画内背景、尺寸比例和内部对齐检查继续保留；错误路径的提示直接提供可用的复跑方式。
- **四角辅助。** AI 先从照片给出粗略四角，脚本在附近寻找连续边线、计算候选交点，再输出原图边线叠加、四角和边缘放大图。由 AI 检查候选是否对准实物，用户不用手工标坐标。
- **按本件实物估计圆角。** 在未加遮罩的拉正照片上分别检查各角，由可靠且相近的角共同提供共享半径候选。证据不足、遮挡或角间分歧会被标出，不要求用户测量圆角，也不套用跨物品的固定半径。
- **边界与内缩分开检查。** 默认不内缩；有卡外背景进入画面的实际证据时才做必要修正，不统一裁掉一个百分比。未核对的诊断参数不能直接进入正式准备步骤。

现有五个尺寸预设保持不变。仍先交付未调色 PNG 初版，颜色调整按需进行。

## 下载与使用

下载本页附件 **restore-collectible-artwork-skill.zip**，解压后将整个同名技能文件夹放入助手支持的技能目录。升级前保留旧版。脚本依赖 Python 3.10+、NumPy 和 Pillow，外观还原仍需宿主提供图像编辑工具。

不支持真实透明输出或能力未知的宿主，应在准备前显式选择 `generation_layout: "full_canvas"`，使用无外边距的编辑输入。脚本不会仅凭比例相符就把任意不透明照片当作已经正确裁切的画面。

部分宿主在会话中途不会刷新技能列表；安装后可新开会话确认是否发现，或在当前会话明确读取已安装的 `SKILL.md`。

## 验证与边界

53 项本地检查通过，解压后的安装包也通过同一组检查。两张既有成品复跑保持 RGBA 像素一致；把一张已有归一小卡作为不透明 RGB 输入的模拟测试，也恢复了相同成品。历史画内背景误抠结果继续被拒绝。这些是本地回归，不是新的真实宿主生成测试。

三张实拍进行了边线和圆角诊断：直角照片保留直角，两张小卡分别提供独立候选；亮面小卡的角间分歧仍需复核。实拍测试使用已有人工四角作为搜索起点，尚未证明陌生照片从零定位的成功率。

**四角工具属于辅助定位，需要 AI 查看对照图后确认，不是全自动物品识别或精确裁切保证。** 共享圆弧适合原本四角同形的平面物品；异形角、严重遮挡和弯曲需单独处理。私人照片与诊断图片不包含在安装包中。生成式视觉还原不等于恢复真实源文件或隐藏内容。
